# React TODO リスト

React の `useState`、コンポーネント、props、配列の `map` を使った TODO リストです。

## 起動方法

```bash
npm install
npm run dev
```

表示された URL（通常は `http://localhost:5173`）をブラウザで開いてください。

## できること

- 入力欄から TODO を追加（Enter または追加ボタン）
- チェックで完了状態を切り替え
- 残りの TODO 件数を自動更新
- 未完了・完了済み・すべての絞り込み
- ブラウザを閉じても残る `localStorage` 保存
